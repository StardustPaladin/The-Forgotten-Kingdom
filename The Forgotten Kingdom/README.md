
# Overview

The Forgotten Kingdom is a text-based Choose Your Own Adventure game written in Python. The player wakes up in a mysterious forest with no memory of how they got there. As they explore, they discover different locations, meet characters, collect items, and make decisions that affect how the story unfolds. The game includes multiple paths and endings based on the choices the player makes.

My purpose for creating this software was to improve my programming skills by building an interactive program with multiple systems working together. I wanted to practice using functions, conditional statements, loops, dictionaries, and file handling while creating something more complex than a basic program. I also wanted to learn how to manage player information, track decisions, create an inventory system, and save and load game progress. This project helped me better understand how different parts of a program can work together to create a complete experience.

[Software Demo Video](https://youtu.be/fVRGky8_QT0)

# Development Environment

I developed this project using Visual Studio Code as my code editor. I used it to write, organize, run, and test the program. I also used GitHub to store and manage the project.

The programming language I used was Python. I used Python's built-in `json` library to save and load player progress and the `pathlib` library to manage the save file. I did not need any external libraries for this project.

The game uses several Python programming concepts, including:
- Functions to organize different parts of the game.
- Variables and dictionaries to store player information.
- Lists to track decisions, discoveries, and collected rewards.
- Loops and conditional statements to handle player choices.
- File handling and JSON to save and load game progress.
- Inventory and player-stat systems to keep track of items, health, and gold.
